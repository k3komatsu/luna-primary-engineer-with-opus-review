- Invocation: allow_implicit_invocation=true; available for implicit selection when relevant

- Workspace: current Git worktree tmp/luna-primary-engineer/reviews/<unique-id>; no system temporary directories or symlinked review roots
- Lifecycle: foreground start/resume; explicit wrapper background/status forms; runner/Claude PID tracking; launched Opus processes are never terminated

- Permission discipline: dontAsk + permission-prompts none + Read/Glob/Grep + Write scoped by exact absolute Edit(//path) only; generic Edit/Bash/notebook/MCP unavailable
- Verification: bash scripts/self-test.sh covers designated-file success, PID state, process-loss confirmation, safe handoff, contract failures, sticky review, network retry, dual, panel, and static guards
